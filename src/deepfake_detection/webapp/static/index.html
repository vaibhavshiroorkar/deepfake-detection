How it works

Every model reads the same prepared clip. The face models see 16 aligned face crops; the audio and lip-sync streams also hear the voice. The equations below are the ones the code trains and evaluates.

Results

FakeAVCeleb is the dataset the models trained on, tested on speakers they never saw. DFDC, Celeb-DF and DF26 are footage from elsewhere. The gap between the two is the main result.

Against prior work

The project set four targets from published results. The historical visual baseline meets its target. The audiovisual, fusion and PE claims require corrected experiments.
