Images, videos and audio files are accepted.

IMAGEVIDEOAUDIO

  1. The file is checked. Its type, streams and length are read; an unsupported or damaged file is refused.
  2. Independent checks run. Each looks for one kind of evidence and reports only on that; a check that does not apply to the file says so.
  3. You get a report. For each check: what was done, what was observed, why the result was reported and what it cannot tell you. There is no overall score.
