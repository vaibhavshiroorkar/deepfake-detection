# Project rules

## Pending work

`docs/PENDING.md` is the single list of open work. Keep it current in every session, without being asked:

- **When planning**, add every new task, decision to make, or follow-up to the right section before starting it. That covers work for Claude and for Vaibhav. Nothing planned lives only in chat.
- **When a task is done**, remove it from the list in the same commit as the work, or in the next commit. Git history keeps what was done; the project log keeps why.
- **When a task changes**, edit it in place: new estimate, new owner, new reason.
- **Before ending a turn** that changed the plan or finished work, check `docs/PENDING.md` against what happened and commit it.
