# Results from before amendment A10

These are the sync-path and H4 results on the locked targets as first computed, before amendment A10 added the YuNet face locator for windows with too few faces. They are kept so the correction can be checked. The corrected results are in the folder of the same name without `-pre-a10`, and that folder's README compares the two.

The receipts here record the paths these files had when they were written, under `runs/p001/sync-targets/` and `runs/p001/h4/`. The files were moved, not changed.
