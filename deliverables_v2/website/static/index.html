      How to read a report

      • A number shown for a check is a model output or a ranking score. It is not a probability and is not a percentage of fake.
      • Uncertainty is stated per check. A check that found nothing does not show that a file is unmanipulated.
      • Checks marked experimental are research prototypes. They never make a finding.
      • Software tests show that this application behaves as designed. They are not a measure of detection accuracy.
