# Website design directions

Three directions for the main site's home page, made on 2026-11-16 to choose a look before building. Each is a full static page with real numbers from the project. Open the HTML file in a browser.

| File | Direction |
|---|---|
| `a-editorial.html` | Editorial: warm paper, a large serif headline, numbers set like journal figures |
| `b-signal.html` | Signal: dark, a bento grid of findings, mono labels, a teal accent |
| `c-casefile.html` | Case file: a forensic dossier with exhibits, stamps and hard black lines |
| `b-signal-v2.html` | B refined after Vaibhav chose B (C rejected): the generated-site defaults removed. Its signature is a speech-loudness and mouth-opening trace that falls out of step for a dubbed clip, with one findings chart and one typeface (Schibsted Grotesk) |

Vaibhav chose B on 2026-11-16 and rejected C. On 2026-11-17 he chose the original `b-signal.html` over v2, keeping v2's useful parts; the result is [`docs/DESIGN.md`](../../DESIGN.md). The scores on the sample detector cards are illustrative, not results.
