How much the file format gives away

A classifier that sees no pixels and hears no speech, only codec, length, bitrate and silence. Its score is the bar any real detector has to beat. Then the same test after we clean every clip the same way.

Three checks, read side by side

Each check scores the clip on its own. The site shows all three, so you can see which one raised the flag.

Face

Looks for blending and texture left by face swaps, frame by frame.

Voice

Listens for the patterns of cloned or synthetic speech.

Lip sync

Asks whether the mouth matches the sound. Trained on real clips only.

One verdict, with a known false-alarm rate

The threshold is set from real clips of the same kind, so about 5 in 100 genuine videos get flagged, not one in three.
