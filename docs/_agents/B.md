## 0. Headline findings (read this first)

1. Of the named face-video seeds, only LAV-DF is clearly obtainable without approval (accept-terms-then-download, needs a Hugging Face account; HF gating mode is `auto`). FaceForensics++ (and Google DFD with it), Celeb-DF v1/v2, Celeb-DF++, FakeAVCeleb, AV-Deepfake1M (and ++), DeeperForensics-1.0, KoDF, FFIW10K are all behind a request form or signed EULA: `EXCLUDED (needs approval)`.
2. DFDC (preview and full) is `UNCLEAR`: Meta's page says an AWS account with IAM keys is required and sends users to `dfdc.ai`, but the `dfdc.ai` host returned "certificate has expired" to my fetch tool on 2026-10-24, so I could not read the sign-up terms or learn whether approval is manual. A Kaggle route exists (secondary source only).
3. WildDeepfake is `UNCLEAR`: files are technically ungated on Hugging Face (72.8 GB) but the official README says "You will need to complete an agreement form to use the dataset".
4. Genuinely open and usable video items besides LAV-DF: DeepfakeTIMIT (0.23 GB, 2018 GAN face swap, 32 subjects; real counterpart VidTIMIT is separately open, 3.2 GB) and TalkingHeadBench (17.3 GB, modern 2024-2025 talking-head generators, identity-disjoint, but FAKE ONLY: the real videos are not in the repository).
5. Audio is well covered by open data: ASVspoof 2019 LA (7.64 GB, direct), ASVspoof 5 (142.3 GB total, Zenodo, ODC-By), In-the-Wild (8.16 GB, licence statements conflict), WaveFake (28.9 GB, fake only, no real audio included).
6. Images are well covered by open data: ForenSynths/CNNDetection ProGAN train (74.9 GB) / val / test (20.05 GB) on Hugging Face, the diffusion test set (875 MB), OpenForensics (56.4 GB, multi-face forgery images), GenImage (links given, size NR), Community Forensics (1.08 TB full; Small 259.7 GB; Eval 206 GB; all can be sharded).
7. Gap, stated plainly in section 4: counting only open datasets that have BOTH real and fake face video with a documented official route, there is exactly one modern-scale set (LAV-DF, one audio generator and one lip-sync generator) plus one tiny 2018 set (DeepfakeTIMIT). That is not a sound train-on-one, test-on-others protocol by itself.

## 4. Gaps

Question: if datasets needing approval are excluded, are there enough open talking-head face-video datasets for a sound generalisation test (train on one, test on others never seen)?

Counting face-video datasets with both real and fake clips and a documented route that needs no human approval:

| Dataset | Real + fake? | Era and generators | Size | Counts |
|---|---|---|---|---|
| LAV-DF | yes (VoxCeleb2 reals) | 2022 data; fake audio from SV2TTS, fake lips from Wav2Lip (one TTS, one lip-sync model) | 25.6 GB | 36,431 real + 99,873 fake videos, 153 identities |
| DeepfakeTIMIT (+ VidTIMIT reals) | yes, two separate records | 2018 autoencoder-GAN swap, 2 model sizes | 0.23 + 3.2 GB | 620 or 640 fake videos, 32 subjects; VidTIMIT 43 people |
| TalkingHeadBench | fake only; reals must be rebuilt from CelebV-HQ (YouTube scraping, attrition) and FF++ (form-gated) | 2024 to 2026 audio/video-driven generators (Hallo, Hallo2, AniPortrait, LivePortrait, EMOPortraits; Hallo3 and MAGI-1 test only) | 17.3 GB | 2,994 fake |
| WildDeepfake (UNCLEAR) | yes (sequences, no audio, no videos) | in-the-wild internet deepfakes, unknown methods | 72.8 GB | 3,805 real + 3,509 fake sequences |
| DFDC (UNCLEAR) | yes | 8 face-swap algorithms, 2019 to 2020 | about 470 GB (third party) | 100,000 fake in train |

Plain assessment:
- With status `OPEN (usable)` and both classes present and complete: 2 datasets (LAV-DF and DeepfakeTIMIT+VidTIMIT). One of them has 640 videos from 2018. That leaves effectively one usable modern-scale talking-head set. A cross-dataset protocol (train on A, test on B, C never seen) cannot be run credibly with one large set and one tiny outdated set.
- If TalkingHeadBench is added with reals rebuilt from CelebV-HQ, the count of independent source families becomes 3, but the real class would be made by a fragile YouTube-download script, and the fake-vs-real source difference (FFHQ stills animated vs YouTube clips) would be a shortcut a model can learn. This would need an explicit control.
- If both `UNCLEAR` sets resolve favourably (WildDeepfake, DFDC), the count becomes 4 or 5, but DFDC (about 470 GB) cannot fit beside the other tiers in 404 GB without subsetting.
- Every face-swap benchmark the literature actually uses for cross-dataset testing (FF++, Celeb-DF v2, DFDC, DFD, DeeperForensics, KoDF, FakeAVCeleb) is excluded or unclear, so numbers from our protocol would not be comparable one-to-one with published DeepfakeBench-style tables (R-017) that train on FF++ and test on Celeb-DF. This is a consequence for the paper's claims, not a decision.
- For audio inside video: LAV-DF supplies independent real and fake audio; TalkingHeadBench supplies fake audio extracted from generated videos but its real audio is only the FF++ clips (704 per README, 596 files in the listing); DeepfakeTIMIT audio is unmodified. FakeAVCeleb and the DFDC audio-edited clips are not available open.
- Speech standalone: no gap. ASVspoof 2019 LA (speaker-disjoint, 2019 generators), ASVspoof 5 (speaker-disjoint, crowdsourced, 2024), In-the-Wild (2022 real-world test), WaveFake (vocoders, fake only). Train-on-one, test-on-others is possible with three independent sources.
- Images: no gap. Train on ForenSynths ProGAN, test on the 2302.10174 sets (GAN and diffusion) plus GenImage or Community Forensics-Eval gives several unseen generators; a face-specific manipulated-image set is OpenForensics (GAN face swaps, 2021). Face-manipulated image data otherwise comes from frames of face-video sets, which links back to the video gap.
