## Method and protocol notes

- Every fact below was read on 2026-10-24 from a page, API response or file I opened (URLs in section (c)). Anything I could not open or could not verify is written NR (not retrieved).
- Hugging Face (HF) file lists, sizes and SHA-256 (LFS oid) come from `https://huggingface.co/api/models/<repo>?blobs=true`. Parameter totals come from `...?expand[]=safetensors` (counted from the safetensors header by HF) and, where a vision tower had to be separated from a text tower, from the safetensors header read with an HTTP Range request (first tens of KB only). No weight file was downloaded.
- Parameter counts of the exact tensors are arithmetic on those headers. Where I subtracted a 1000-class classifier to get the backbone, that is marked "(arithmetic)".
- Memory columns are ESTIMATES made by me with a stated formula (see "Estimate method"); they are not measurements and must be measured later on the RTX 5070 (CLAUDE.md rule 1).
- Python 3.13 installability: a dry-run resolution in a temporary virtual environment (`uv venv --python 3.13`, then `uv pip install --dry-run "torch==2.14.1" timm open_clip_torch transformers`) in the scratchpad folder, not in the project `.venv`. Result on 2026-10-24: "Resolved 41 packages", with torch==2.14.1, timm==1.0.30, open-clip-torch==3.3.0, transformers==5.20.2, torchvision==0.29.1, huggingface-hub==2.3.0, safetensors==0.8.0, numpy==2.5.4, pillow==13.0.0. Nothing was installed. PyPI also lists a `torch-2.14.1-cp313-cp313-win_amd64.whl` file. Requires-Python from PyPI JSON: timm >=3.8, open_clip_torch >=3.9, transformers >=3.10.0, torch >=3.10.
- Library versions needed by DINOv3: the DINOv3 GitHub README says "supported ... by released versions of the Hugging Face Transformers library starting with version 4.56.0" and "supported by the PyTorch Image Models / timm library starting with version 1.0.20"; both are below the versions resolved above.
- Loading from a local folder after one download is the normal path of all three libraries, but I did not test offline loading here. NR (to be tested when the weights are downloaded).

## Selection criteria (stated first, applied to every row)

1. Licence verified from the weights' own repository: HF model card licence tag AND the LICENSE file or licence text of that repository, plus gating or usage restriction. Commercial-allowed versus research-only stated plainly. Gated (needs approval) versus automatic. Training-data licence noted separately when a card states one.
2. Weights downloadable and usable offline: exact file names, sizes in bytes, SHA-256, loading library, installability on Python 3.13 with torch 2.14.1.
3. Fits in 12 GB: parameters, native input resolution, ESTIMATED fp16 inference memory at batch 64, ESTIMATED plausibility of full fine-tuning at batch 16 with mixed precision.
4. Feature size: the dimension of the standard pooled embedding before any classifier head, with the exact tensor.
5. Diversity of families.

## Estimate method (applies to every memory cell)

- Inference fp16, batch 64 = weights at 2 bytes per parameter + 3 times the largest single activation tensor (batch x tokens x MLP width x 2 bytes for a ViT; batch x largest feature map x 2 bytes for a CNN). It excludes the CUDA context and allocator overhead (assume roughly 0.5 to 1 GiB extra). Attention is assumed to use a fused kernel.
- Full fine-tune, batch 16, mixed precision = 16 bytes per trainable parameter (fp32 weights 4 + gradients 4 + AdamW two moments 8) + activations. ViT activations per layer = tokens x batch x hidden x C bytes, with C = 34 (fused attention) to about 54 (eager attention), summed over layers. CNN activations = (timm model-card "Activations (M)" figure) x 16 x 2 bytes x 3 (my assumed factor for saved BN and activation tensors). The ViT coefficient C and the factor 3 are my own back-of-envelope assumptions, source NR. Treat results as plausible/implausible only.
- Token counts: ViT-x/14 at 224 = 16x16 patches + 1 class token = 257. ViT-x/16 at 224 = 196 patches + 1 = 197 (CLIP B/16), 196 (SigLIP, no class token), 201 for DINOv3 (1 class + 4 register + 196 patch, per its card).
